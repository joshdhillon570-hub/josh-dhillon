# Josh Dhillon — Personal Portfolio

A GitHub-ready personal portfolio built with plain HTML, CSS and JavaScript.

## Quick setup

1. Open `index.html` in a browser to preview it.
2. Replace the `YOUR PHOTO` placeholder with your own image:
   - Put it in `assets/profile.jpg`
   - In `index.html`, you can replace the profile placeholder with an `<img>` if desired.
3. Open `script.js` and edit the `projects` and `certificates` arrays.
4. Replace the GitHub, LinkedIn and email placeholders.
5. Upload the folder to a GitHub repository.
6. Enable **GitHub Pages** from the repository's Settings → Pages.

## Adding certificates

Put certificate images inside:

`assets/certificates/`

Then add an entry to the `certificates` array in `script.js`.

Recommended image format: JPG or PNG.
